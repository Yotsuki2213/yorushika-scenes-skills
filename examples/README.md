# 使用示例 / Usage examples

这里提供两个技能的调用方式和输入条件。示例以文字说明为主，不附个人照片、生成作品或历史 MV 截图。

| 路径 / Workflow | 说明 / Guide |
| --- | --- |
| 照片 → MV 场景 | [mv-scene.md](mv-scene.md) |
| 照片 → MV → 明信片 | [从照片开始](postcard.md#从照片开始) |
| 横向 MV → 明信片 | [上图下文，默认2组日中歌词](postcard.md#横向-mv上图下文) |
| 竖向 MV → 明信片 | [左图右文，默认4组日中歌词](postcard.md#竖向-mv左图右文) |
| 明信片控制 | [预览配文或关闭文字](postcard.md#预览配文或关闭文字) |

后续经明确选择的作品案例可以按“输入说明 → 处理决策 → 输出”归档；包含图片时应先确认上传范围及素材权利。图片生成任务本身不自动构成将照片提交到仓库的授权。

These guides document invocation and inputs. No personal photographs or generated project images are bundled. Add image-based case studies only after selecting their scope and confirming permission to upload the material.
