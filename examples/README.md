# 使用示例 / Usage examples

这里提供两个技能的调用方式、输入条件和检查要点。初始版本不上传个人照片、生成作品或MV截图。

| 路径 / Workflow | 说明 / Guide |
| --- | --- |
| 照片 → MV 场景 | [mv-scene.md](mv-scene.md) |
| 照片或MV图 → 明信片 | [postcard.md](postcard.md) |

后续经明确选择的作品案例可以按“输入说明 → 处理决策 → 输出 → 检查记录”归档；包含图片时应先确认上传范围及素材权利。图片生成任务本身不自动构成将照片提交到仓库的授权。

These guides document invocation and acceptance checks. No personal photographs or generated project images are bundled. Add image-based case studies only after selecting their scope and confirming permission to upload the material.
