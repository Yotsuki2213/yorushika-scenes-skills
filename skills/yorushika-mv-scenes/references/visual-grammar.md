# Yorushika MV Scenes：视觉语法

本文件记录从本地《ただ君に晴れ》和《藍二乗》截图中提炼的可重组场景语法。它不是截图索引，也不是逐帧复制指南；生成时只取结构、光色、材质和情绪关系。

## 共同骨架

- 先按 EXIF 校正后的输入方向确定画幅：横图约 16:9、竖图约 3:4，正方形默认约 16:9；比例是构图参考，接受生成器自然输出的接近比例。横图延续横向空间节奏，竖图保留纵向轴线；天空、墙面、海面与人物共同组织留白。
- 人物处理跨路线统一：无人物主体时添加一个略抽象、潦草但清楚可辨的白色排线人物，身体背对镜头、头部自然越肩回望，关节、重心与落点符合现实逻辑；有人物主体时保留身体与原姿态，不强行扭转。两种分支都以密集白色排线、横向涂抹覆盖整个可见头部，包括头顶、头发、脸、耳与后脑。身份不承担叙事，空间和动作承担叙事。具体分支与参考图见 [人物处理](human-treatment.md)。
- 蓝—白是最稳定的冷色骨架，暖色只在阳光、木材、沙土、皮肤或室内灯光处出现。
- 真实摄影与手绘/水彩/印刷痕迹并置：轻微失焦、运动拖影、颗粒、透明叠层、涂抹边缘和 RGB 色差可以作为节奏，而不是全画面滤镜。
- 文字是稀疏的图形构件，最多一处短句；不得把歌词、标题或播放器界面当作可复制内容。

## graphic-soliloquy／线稿独白

适合建筑、室内、书桌、道路、符号或有明显轮廓线的参考图。

- 线条：粗细不匀、略带手绘抖动；场景轮廓可有轻微蓝/红错位，线稿小人则必须使用纯白线条。
- 色彩：深蓝、钴蓝、黑、脏白为主，暖色小面积点亮。
- 构图：几何门框、窗格、桌面、书本或道路形成秩序；新增人物的大小与动作由透视和叙事决定，已有主体的身体比例与位置保留。
- 质感：二维动画背景、干刷、印刷错位、细颗粒；避免过度精致的商业插画。

### graphic-soliloquy 的保留式叠加

当用户要求“保留原素材”时，原图是可见的底层，不是仅供参考的语义草图：

- 锁定原人物身体、姿态、主要物件、几何、水平线/消失点、前景材质和光线方向；可见头部覆盖区与新增人物落点明确列为可编辑区，不移动相机或替换主要物件。
- 只在局部可编辑区叠加不规则墨线/石墨线、少量钴蓝或暗红套色错位、一次干刷擦除和细纸纹。
- 按 style_intensity 控制支持性效果：restrained 约 10–30%、strong 约 30–55%、expressive 约 45–65%；人物可辨性和必要的头部遮盖不被强度档位取消，其余区域保留原有纹理、色彩和景深。
- 让线稿沿着原有边缘“说话”，不要把整张照片统一变成水彩、赛璐璐或商业插画。
- 若需去水印，只修补水印紧邻的天空、海面、岩石或纸张纹理；不顺手删除其他原生文字或标记。

### 强 Yorushika 元素的层级

强烈的 Yorushika 风格，不要只增加描边，而要在原构图上建立三层有因果关系的介入：

1. **人物处理（主层）**：按人物分支添加一个有明确动作和真实接触的白色线稿主体，或在保留原人物身体的前提下覆盖可见头部。绘制层使用纯白墨线、铅笔线或粉笔感笔触；新人物身体以潦草断线、疏密排线与透底间隙形成体积，背身回头的姿态仍须自然；整个可见头部须密集横向涂抹，不能只遮脸或只描轮廓。人物层级由源图与叙事决定，不固定为极小点缀；保留原人物身体比例。
2. **水墨水彩场（次层）**：让一片有边界的水墨或水彩晕染跟随原图的主导手势，出现渗化、积色、干刷缺口和透明叠层。它可以覆盖一个较大的视觉场，但必须让原照片纹理在旁边或下方继续可读。
3. **失真破碎（断裂层）**：只选择一次主要断裂，例如错位轮廓、撕裂套色、短段扫描线断开、RGB 偏移或破碎边缘，并把它对齐到海岸、浪花、岩石层理或其他真实边界。禁止随机噪波铺满画面。

强度由覆盖面积和介入的连贯性决定，不由效果数量决定：`strong` 可让结构化介入达到约 30–55% 画面，`expressive` 可达到约 45–65%，但主体、主要几何、光线方向和语义最小集仍需保持。三层效果必须共享同一个源形状、轴线或视线路径，形成“构图先成立，风格后爆发”的关系。

## sunlit-memory／盛夏回忆

适合海边、天空、田野、住宅区、车站、坡道和强日光参考图。

- 色彩：淡天蓝、暖象牙、草绿、赭黄、低饱和粉；高光允许轻微漂白。
- 构图：沿原图横向水平线或纵向空间轴线组织空气感；新增人物可偏置，天空/海面继续承担情绪空间。
- 人物：执行共同人物分支。新增人物根据场景选择背身行走或停驻后自然回头的瞬间；已有主体保留身体与姿态并覆盖整个可见头部，不以空场或半透明身影替代必需的人物处理。
- 质感：清洁手绘背景、薄雾、柔焦、轻微镜头晕光；保留海水、沙地、风和衣料的触感。

## nocturnal-material／暗场物质

适合暗室、稀疏舞台、单点光源、孤立物件或材质事件明显的参考图。

- 色彩：藏蓝、黑、冷灰、棕褐，暖光只负责聚焦。
- 构图：大块暗部包围一个人或物，留出沉默的负空间；可用长影或墙面投影延长情绪。
- 材质：水、花、玻璃、纸、尘、布或火光只选一个主事件，避免材质堆砌。
- 人物：执行共同人物分支。让白色排线或头部涂抹在现有暗部、光池中清楚可见；保护原身体与环境关系，不因暗场路线而省略人物处理。

## 融合规则

`auto` 先选一个主路由，再以少量兼容特征辅助。`fusion` 固定使用主路由 60%、次路由 25%、第三路由 15%，保持主路由的构图和色彩可辨识。禁止三种模式等量混合。
