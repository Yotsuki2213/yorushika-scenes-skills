# Yorushika Logo Assets

- Source: [Yorushika official website](https://yorushika.com/)
- Retrieved: 2026-08-30
- Source element: inline SVG symbol `logo-side`, used by the site's header logo.
- Original viewBox: `0 0 319.55 70.48`.
- Content: horizontal emblem plus the Japanese name 「ヨルシカ」.

## Packaged files

- `yorushika-logo.svg`: standalone wrapper around the site's original symbol contents. All 18 vector paths and their geometry are retained; the wrapper adds an SVG namespace, viewport dimensions and an inherited monochrome color.
- `yorushika-logo-black.png`: transparent black rendition, 2048 × 452 pixels, for light postcard stock, including tinted paper.
- `yorushika-logo-white.png`: transparent white rendition, 2048 × 452 pixels, for dark postcard stock, including tinted paper.

The PNGs were rendered from the same vector geometry with resvg-py 0.5.0. Only inherited color and output viewport differ. They contain no baked-in background.
